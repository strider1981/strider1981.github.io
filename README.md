# Amit Kale — Portfolio

A responsive single-page portfolio covering technical architecture, location technology, cloud platforms and AI integration.

Static HTML, CSS and JavaScript. No build step. Serve the repository root with a static HTTP server to preview. The main content works without JavaScript; the terminal Easter egg uses a native dialog.

## Hosting

Published through GitHub Pages from `main` at `/`. The GitHub Pages custom domain is `amitkale.in`, declared in `CNAME` and in the Pages settings. GoDaddy DNS must point to GitHub Pages for the domain and certificate to work.

Replace parking website records; preserve mail and unrelated DNS records. Add `amitkale.in` in GitHub Pages settings before saving DNS changes. Enable HTTPS when GitHub issues the certificate.
